# 个人作品集网站

深色主题的前端开发者个人作品集，展示个人信息、技能栈和项目经历。

## 在线预览

[https://WadePan1017.github.io/portfolio/](https://WadePan1017.github.io/portfolio/)

## 技术栈

- **框架：** Vue 3 + Composition API
- **构建工具：** Vite
- **样式：** Tailwind CSS
- **部署：** GitHub Pages

## 功能特性

- Hero 首页：个人介绍与 CTA 按钮
- 关于我：个人背景、经历、数据统计
- 技能栈：进度条可视化展示前端、视觉创作、综合素质
- 项目展示：卡片式项目列表，含技术标签与在线预览链接
- 联系我：联系信息 + 留言表单
- 响应式布局：适配手机、平板、桌面端

## 项目亮点

- 使用 Claude Code 辅助开发，高效完成组件搭建与样式调整
- 深色主题设计，视觉层次分明
- 平滑滚动导航，锚点定位
- 组件化架构，结构清晰易维护
- 响应式适配：Tailwind 断点覆盖全设备

## 本地运行

```bash
# 克隆项目
git clone https://github.com/WadePan1017/portfolio.git
cd portfolio

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
